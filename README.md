# Дизайн сетей ЦОД
Репозиторий с практическими работами по курсу OTUS «Дизайн сетей ЦОД».

## Лабораторный стенд
- PNETLab
- Arista vEOS
- Локальный виртуальный стенд

## Домашние работы
По мере прохождения курса здесь будут размещаться выполненные лабораторные работы, конфигурации сетевого оборудования, схемы и результаты проверки.

## Структура репозитория
Каждая лабораторная работа размещается в отдельной директории и содержит:
- README.md — описание задания и выполненной работы;
- схему сети;
- конфигурации устройств;
- результаты проверки работы сети.
